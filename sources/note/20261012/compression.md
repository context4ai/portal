# 知识压缩比实测（脱敏）

本笔记是 Portal 首页“压缩而非照抄”区块与原理“证据链与索引优先”“Indexer 体系”篇章的来源。数据取自一个大型生产全栈 Monorepo（前后端知识兼有）的 Context 知识工作区，只保留汇总数字，不包含业务名、仓库、路径或文章内容。

## 统计口径

- 统计日期：2026-10-08；工作区为团队实际使用的知识库。
- 代码：知识来源登记的 7 个代码模块中，有 2 个仓库在本地保留了登记提交的完整检出，只统计这 2 个。按扩展名统计源代码文件（ts、tsx、js、jsx、go、vue、less、scss、css、py、proto、thrift），排除 `node_modules`、`dist`、`.git`、`*.d.ts` 与压缩产物。
- 文档：登记的在线文档快照中的 Markdown 正文。
- 知识：`knowledge/` 下已审核的 Markdown 文章（含 frontmatter 与来源标注）。
- 体积按 UTF-8 字节计，未统计 Token。

## 结果

| 项 | 数量 | 体积 |
| --- | ---: | ---: |
| 源代码文件（2 个仓库） | 33,727 个，约 584 万行 | 约 200 MB |
| 文档快照 | 1,129 份 | 约 1.77 MB |
| 已审核知识 | 220 篇（架构 49、业务 93、FAQ 3、SOP 75） | 约 1.75 MB |

- 来源合计约 202 MB，知识约 1.75 MB，体积约为来源的 1/115。
- 其余 5 个代码模块未计入来源，实际压缩比高于 115:1。

## 如何表述

- 可以说：“在一个大型生产全栈 Monorepo 中，可本地统计的两个仓库约 3.4 万个代码文件、584 万行，加上 1,100 余份文档，压缩为 220 篇已审核知识，体积约为来源的 1/115。”
- 必须同时说明：只统计了部分来源，压缩比是下限；压缩比衡量的是体积，不代表知识覆盖率或质量，质量见检索测评。
- 不说“覆盖全部代码”“无损”。知识只保留回答问题需要的事实，每条结论保留指向代码行或文档章节的来源。
